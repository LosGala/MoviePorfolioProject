# Movie Portfolio Project

## Overview
Comprehensive exploratory data analysis (EDA) on a movie dataset. Focused on data cleaning, outlier detection, and identifying key patterns in film revenue and budgets.

## Objectives
- Clean and preprocess raw movie data (missing values, outliers, duplicates)
- Analyze correlations between budget, revenue, and profitability
- Visualize trends across genres, release years, and studios
- Apply anomaly detection to identify unusual revenue patterns

## Tech Stack
- Python · Pandas · NumPy
- Matplotlib · Seaborn
- Jupyter Notebook

## Security Relevance
Demonstrates ETL pipeline skills, data validation, and anomaly detection on large datasets — directly transferable to log analysis and threat hunting workflows.
